# Panduan Pengguna SIMRS ZEN

Panduan ini menjelaskan cara menggunakan sistem SIMRS ZEN untuk berbagai modul dan fungsionalitasnya.

## 1. Pengenalan Sistem

SIMRS ZEN adalah sistem informasi rumah sakit yang dirancang untuk mendukung berbagai aspek operasional rumah sakit, termasuk pelayanan medis, administrasi, keuangan, dan manajemen sumber daya.

### Fitur Utama:
- Manajemen pasien (registrasi, rekam medis elektronik)
- Rawat jalan dan rawat inap
- Laboratorium dan radiologi
- Farmasi
- Keuangan dan akuntansi
- Sistem informasi nasional (BPJS, SATU SEHAT)
- Portal pasien

## 2. Autentikasi dan Otorisasi

### Login ke Sistem
1. Buka browser dan akses URL sistem
2. Masukkan username dan password
3. Klik tombol "Login"
4. Sistem akan mengarahkan ke dashboard sesuai peran pengguna

### Peran Pengguna:
- Administrator: Akses penuh ke semua modul
- Dokter: Akses ke modul pelayanan medis
- Perawat: Akses ke modul keperawatan
- Apoteker: Akses ke modul farmasi
- Petugas Administrasi: Akses ke modul registrasi dan keuangan

## 3. Modul Rawat Inap

### Manajemen Kamar
1. Akses menu "Rawat Inap" > "Manajemen Kamar"
2. Lihat status ketersediaan kamar
3. Assign pasien ke kamar kosong
4. Update status kamar sesuai kebutuhan

### Monitoring Pasien
1. Akses menu "Rawat Inap" > "Monitoring Pasien"
2. Pilih pasien yang akan dimonitor
3. Catat tanda vital pasien
4. Pantau kondisi pasien secara real-time

## 4. Modul Farmasi

### Manajemen Resep
1. Akses menu "Farmasi" > "Manajemen Resep"
2. Lihat daftar resep dari dokter
3. Verifikasi resep dan periksa interaksi obat
4. Proses distribusi obat ke pasien

### Inventaris Obat
1. Akses menu "Farmasi" > "Inventaris Obat"
2. Lihat stok obat yang tersedia
3. Tambahkan stok obat baru
4. Monitor obat yang mendekati tanggal kadaluarsa

## 5. Modul Radiologi

### Manajemen Permintaan Pemeriksaan
1. Akses menu "Radiologi" > "Manajemen Permintaan"
2. Lihat daftar permintaan pemeriksaan dari klinisi
3. Jadwalkan pemeriksaan sesuai ketersediaan alat
4. Catat hasil pemeriksaan setelah selesai

### DICOM Viewer
1. Akses menu "Radiologi" > "DICOM Viewer"
2. Pilih studi pasien yang akan dilihat
3. Gunakan alat untuk mengukur atau menambahkan anotasi
4. Interpretasi hasil dan simpan laporan

## 6. Modul Keuangan

### Laporan Keuangan
1. Akses menu "Keuangan" > "Laporan Keuangan"
2. Pilih periode laporan
3. Lihat laporan laba rugi, neraca, atau arus kas
4. Ekspor laporan dalam format yang diinginkan

### Manajemen Gaji
1. Akses menu "Keuangan" > "Manajemen Gaji"
2. Pilih bulan penggajian
3. Periksa data kehadiran pegawai
4. Proses dan distribusikan gaji

## 7. Modul IGD

### Manajemen Kasus Darurat
1. Akses menu "IGD" > "Manajemen Kasus"
2. Tambahkan kasus darurat baru
3. Tentukan tingkat triage pasien
4. Pantau penanganan kasus secara real-time

### Manajemen Fasilitas
1. Akses menu "IGD" > "Manajemen Fasilitas"
2. Lihat ketersediaan tempat tidur dan peralatan
3. Assign fasilitas ke pasien sesuai kebutuhan
4. Update status fasilitas setelah digunakan

## 8. Integrasi Nasional

### BPJS
1. Akses menu "Integrasi" > "BPJS"
2. Verifikasi data peserta BPJS
3. Buat surat kontrol atau rujukan
4. Sinkronisasikan data ke sistem VClaim

### SATU SEHAT
1. Akses menu "Integrasi" > "SATU SEHAT"
2. Lihat status koneksi ke SATU SEHAT
3. Sinkronisasikan data kesehatan ke SATU SEHAT
4. Pantau hasil sinkronisasi

## 9. Troubleshooting

### Masalah Umum:
- Tidak bisa login: Periksa username dan password
- Tidak bisa akses modul: Pastikan peran pengguna memiliki izin
- Data tidak muncul: Coba refresh halaman atau hubungi administrator

### Dukungan:
Hubungi tim IT rumah sakit atau layanan dukungan SIMRS ZEN jika mengalami masalah yang tidak tercantum di panduan ini.
